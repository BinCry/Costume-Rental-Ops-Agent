# Ops Agent

Ops Agent là năng lực hỗ trợ nhân viên vận hành được phát triển song song trong ứng dụng riêng. Nó bổ sung cho các luồng web thuê trang phục; không thay thế hoặc âm thầm sửa nghiệp vụ của Costume Rental Studio.

## Phạm vi dự kiến

- Hỏi đáp SOP/nghiệp vụ bằng tiếng Việt, có dẫn nguồn và mức độ xác minh.
- Tổng hợp việc cần chú ý từ nguồn dữ liệu được cấu hình.
- Đề xuất checklist và bước tiếp theo; không giả lập đã cập nhật đơn, bộ hoặc tiền.
- Phân quyền, nguồn dữ liệu và audit thuộc hệ thống Ops Agent khi được triển khai.

Prototype hiện dùng fixture. Chưa có model, backend, API live, ingestion hoặc thao tác nghiệp vụ thật.
