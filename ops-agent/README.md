# Ops Agent

Ops Agent là capability bổ sung cho phần vận hành của bản web được phát triển trong repo này. Nền UI/UX và các luồng Studio được mang về để phát triển song song, giữ nhất quán với repo Costume Rental Studio gốc.

## MVP đề xuất

1. Hỏi đáp SOP/nghiệp vụ bằng tiếng Việt, có trích dẫn và nhãn mức độ tin cậy.
2. Tóm tắt việc cần chú ý theo dữ liệu tổng hợp hoặc provider được cấu hình.
3. Chuẩn bị checklist/bước tiếp theo; không giả lập đã cập nhật đơn, bộ hoặc tiền.

Frontend nền hiện vẫn là bản demo fixture. API, xác thực/danh tính dùng chung và nguồn dữ liệu live chưa được xác định. Xem [yêu cầu](../docs/product-requirements.md), [source review](../docs/source-review.md) và [manifest tài nguyên Studio](context/studio-reference/README.md).
