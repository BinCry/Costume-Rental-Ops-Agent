# Frontend — Costume Rental Ops Agent

Frontend React, TypeScript, Vite và Tailwind CSS. Giao diện nền giữ cùng visual direction với Costume Rental Studio; ứng dụng này chạy độc lập trong repo riêng.

Các màn nghiệp vụ và Ops Agent hiện dùng fixture. Chưa có backend nghiệp vụ thật hoặc API live.

Chạy từ repo root:

```powershell
pnpm install
pnpm dev
```

Xem [yêu cầu sản phẩm Ops Agent](../../docs/product-requirements.md) để biết phạm vi hiện tại và các giai đoạn tiếp theo.
