# Product docs

Tài liệu mô tả bản Costume Rental Studio nền được phát triển song song trong repo này và phần Ops Agent bổ sung.

## Đọc theo thứ tự

1. [Source review](source-review.md) — nguồn nào đã đọc và giới hạn xác minh.
2. [Product direction](product-direction.md) — mô hình phát triển song song và vai trò của Agent.
3. [Product requirements](product-requirements.md) — yêu cầu chức năng/phi chức năng và tiêu chí chấp nhận.
4. [UI parity](ui-parity.md) — quy trình giữ domain, luồng và thiết kế nhất quán giữa hai repo.

Handoff, tài liệu nghiệp vụ và các bản sao nguồn nằm trong [`../ops-agent/context/`](../ops-agent/context/). Frontend nền được lưu tại [`../apps/web/`](../apps/web/); manifest tài liệu UI/UX ở [`../ops-agent/context/studio-reference/`](../ops-agent/context/studio-reference/).

**Trạng thái:** tài liệu v0.3 là định hướng/yêu cầu đang hoàn thiện. Snapshot được dùng làm baseline có provenance; cần đối chiếu commit với repo Studio trước khi coi nó là trạng thái hiện hành.
